# 数式

import BrowserFrame from '@site/src/components/BrowserFrame';

数式は [KaTeX](https://katex.org) を使って表示できます。

有効化方法は [下記](#configuration) を参照してください。

## 使い方 {#usage}

詳細は [KaTeX](https://katex.org) のドキュメントを参照してください。

### インライン {#inline}

インライン数式は、LaTeX の式を `$` で囲んで書きます。

```latex
Let $f\colon[a,b]\to\R$ be Riemann integrable. Let $F\colon[a,b]\to\R$ be
$F(x)=\int_{a}^{x} f(t)\,dt$. Then $F$ is continuous, and at all $x$ such that
$f$ is continuous at $x$, $F$ is differentiable at $x$ with $F'(x)=f(x)$.
```

### ブロック {#blocks}

ブロック数式、つまり display mode では改行と `$$` を使います。

```latex
$$
I = \int_0^{2\pi} \sin(x)\,dx
$$
```

## 数式表示を有効にする {#configuration}

KaTeX を有効化します。

1. `remark-math` と `rehype-katex` plugin を install します。

    ```bash npm2yarn
    npm install --save remark-math@6 rehype-katex@7
    ```

    :::warning

    Docusaurus v3（MDX v3）では `remark-math 6` と `rehype-katex 7` を使ってください。他の version の動作は保証できません。

    :::

2. この 2 つの plugin は [**ES Modules**](https://gist.github.com/sindresorhus/a39789f98801d908bbc7ff3ecc99d99c) のみです。[**ES Modules**](https://flaviocopes.com/es-modules/) の config file を使うことを勧めます。

    ```js title="ES module docusaurus.config.js"
    // highlight-start
    import remarkMath from 'remark-math';
    import rehypeKatex from 'rehype-katex';
    // highlight-end

    // highlight-start
    export default {
      presets: [
        [
          '@docusaurus/preset-classic',
          {
            docs: {
              path: 'docs',
              // highlight-start
              remarkPlugins: [remarkMath],
              rehypePlugins: [rehypeKatex],
              // highlight-end
            },
          },
        ],
      ],
    };
    ```

        <details>

    <summary>
      [**CommonJS**](https://nodejs.org/api/modules.html#modules-commonjs-modules)
      の config file を使う場合
    </summary>

            CommonJS config file を使う場合でも、dynamic import と async な config creator function によって ES module plugin を読み込めます。

    ```js title="CommonJS module docusaurus.config.js"
    // highlight-start
    module.exports = async function createConfigAsync() {
      // highlight-end
      return {
        presets: [
          [
            '@docusaurus/preset-classic',
            {
              docs: {
                path: 'docs',
                // highlight-start
                remarkPlugins: [(await import('remark-math')).default],
                rehypePlugins: [(await import('rehype-katex')).default],
                // highlight-end
              },
            },
          ],
        ],
      };
    };
    ```

        </details>

3. config の `stylesheets` に KaTeX の CSS を含めます。

    ```js
    export default {

      stylesheets: [

      ],
    };
    ```

## KaTeX アセットを self-host する {#self-hosting-katex-assets}

stylesheet、font、JavaScript library を CDN から読むのは、popular library や asset では一般に便利です。host すべき asset 量が減るためです。`katex.min.css` と必要な KaTeX font を self-host したい場合は、[KaTeX GitHub releases](https://github.com/KaTeX/KaTeX/releases) から最新 version をダウンロードし、`katex.min.css` と `fonts` directory（`.woff2` だけでも多くの場合は十分）を site の `static` directory へ置いてください。その上で `docusaurus.config.js` の stylesheet `href` を CDN URL からローカル path（例: `/katex/katex.min.css`）へ差し替えます。

```js title="docusaurus.config.js"
export default {
  stylesheets: [
    {
      href: '/katex/katex.min.css',
      type: 'text/css',
    },
  ],
};
```
