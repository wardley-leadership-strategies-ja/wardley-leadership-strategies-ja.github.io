# Priceless: The Myth of Fair Value

William Poundstone の **Priceless: The Myth of Fair Value (and How to Take Advantage of It)** は、行動価格設定と、公正さの認知が購買判断へ与える影響を掘り下げます。心理学と行動経済学の実験を通じて、アンカリング、デコイ価格、その他の手法が支払意思額をどう変えるかを示します。

フレーミング、文脈、小さな設計の違いが価格受容をどう左右するかを理解する助けになり、価格方針とユーザー認知の力学を揃えたいチームに向いています。
