# Fast Second

**Fast Second: How Smart Companies Bypass Radical Innovation to Enter and Dominate New Markets** で Constantinos C. Markides と Paul A. Geroski は、先行者が需要を証明するのを待ってから攻勢に出る企業を分析します。不確実性が下がった段階で、優れた資産、流通、タイミングを使えば、後発でも素早く拡大できると論じます。

いつ飛び込むべきかを見極める方法、先行者との提携や買収、素早い追随実行を支える組織設計まで扱っており、忍耐と決断を両立させたいリーダーに役立ちます。
