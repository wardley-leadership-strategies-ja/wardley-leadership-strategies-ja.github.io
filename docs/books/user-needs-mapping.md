# User Needs Mapping

Rich Allenの**User Needs Mapping**は、Wardley Mapを描く前に、表明されたニーズ、当然視されるニーズ、将来ニーズを体系的に整理する方法を示します。地図を実際の需要にしっかり結びつけたままにしやすくします。

実務的な問いかけやワークショップ技法に重点を置き、ニーズの洗い出し、順序づけ、その洞察をより明確なバリューチェーンと進化段階へ翻訳する流れを具体的に説明します。
