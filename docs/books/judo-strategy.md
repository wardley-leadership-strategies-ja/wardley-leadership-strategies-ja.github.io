# Judo Strategy

**Judo Strategy**でDavid B. YoffieとMary Kwakは、小さな企業が既存勢力の強さと勢いを逆手に取る方法を分析します。武道の比喩と事例を通して、素早い動き、レバレッジ、均衡によって巨大企業の規模を負債へ変える戦術を描きます。

提携構築、標準形成、既存勢力が反応しにくい隙間市場への攻撃などを扱っており、正面衝突を避けながら参入障壁を崩したい挑戦者に向いた実践書です。
