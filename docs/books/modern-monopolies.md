# Modern Monopolies

**Modern Monopolies** で Alex Moazed と Nicholas L. Johnson は、プラットフォーム企業がどう価値を生み、どう獲得するかを解説します。多面市場、ネットワーク効果、データ駆動のフィードバックループの経済性を整理し、なぜプラットフォーム企業が従来型企業を追い抜けるのかを示します。

技術、小売、交通などの事例を通じて、プラットフォームの立ち上げ、エコシステムの統治、参加の収益化を論じており、プラットフォーム優位を築く、あるいはそれと競うリーダーに向いた現場ガイドです。
