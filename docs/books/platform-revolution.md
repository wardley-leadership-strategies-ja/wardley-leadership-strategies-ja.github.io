# Platform Revolution

Geoffrey G. Parker、Marshall W. Van Alstyne、Sangeet Paul Choudaryによる**Platform Revolution: How Networked Markets Are Transforming the Economy—and How to Make Them Work for You**は、プラットフォーム企業が生産者と消費者の相互作用をどう統率するかを解説します。

ネットワーク効果、ガバナンス、価格戦略など、プラットフォームの立ち上げと拡大に必要な概念を整理し、業界横断でプラットフォーム型エコシステムを育てる実務枠組みを提供します。
