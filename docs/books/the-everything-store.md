# The Everything Store

Brad Stoneの**The Everything Store: Jeff Bezos and the Age of Amazon**は、Amazonがオンライン書店から多角的なプラットフォームへ成長した過程を描きます。物流、マーケットプレイス、AWS、徹底した顧客志向と節約文化が成長の土台になったことを詳述します。

Amazonが供給者とどう向き合い、パートナーと交渉し、規模を使ってエコシステム全体へ影響を及ぼすかを知るうえで有用で、買い手と供給者の力関係やプラットフォーム戦略の実行を理解する助けになります。
