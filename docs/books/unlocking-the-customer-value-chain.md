# Unlocking the Customer Value Chain

Thales S. TeixeiraとGreg Piechotaによる**Unlocking the Customer Value Chain**は、破壊的企業が顧客ジャーニーの一部を切り離して市場シェアを奪う方法を説明します。Amazon、Warby Parker、Airbnbなどの事例を通じて、既存勢力のバリューチェーンにある摩擦点を新興企業がどう突き、その後に自分たちのプラットフォーム上で再バンドルするかを示します。

顧客活動を地図化し、どこで価値を取れるかを見つけ、参入から本格的なプラットフォーム展開までの順序を設計する枠組みを提供しており、中抜きやD2Cシフトを評価する戦略担当に役立ちます。
