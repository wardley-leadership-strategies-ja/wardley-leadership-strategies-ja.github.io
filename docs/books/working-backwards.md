# Working Backwards

Colin BryarとBill Carrの**Working Backwards**は、Amazonのリーダーシップ原則とプロダクト開発メカニズムを記録した本です。PR/FAQ、単一責任リーダー（single-threaded leadership）、指標主導の運用卓越性といった仕組みを通じて、チームが顧客成果から出発してローンチへ向けて反復する方法を説明します。

Amazonの成長に関する逸話と、それを他組織へ持ち込むための指針を組み合わせ、文書中心の意思決定、厳格な入力指標、顧客執着を保ったまま実験を拡大する仕組みの重要性を強調します。
