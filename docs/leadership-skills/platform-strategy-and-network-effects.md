# プラットフォーム戦略とネットワーク効果

参加が増えるほど価値が高まるプラットフォームを設計し、拡大し、防衛するスキルです。

## 🎯 **何を可能にするか**

多面市場のインセンティブを均衡させ、エコシステム崩壊を避けるのに役立ちます。

## 🧭 **どう育てるか**

- 中核となる交換関係を明確にし、双方の摩擦を低く保つ。
- 価格設定や補助で初期のネットワーク効果を立ち上げる。
- 中抜きリスクやプラットフォーム包囲の脅威を監視する。
