# 戦略的センスメイキング

状況を読み、弱いシグナルを解釈し、戦略が次に進むべき方向について一貫した見立てをつくる規律です。

## 🎯 **何を可能にするか**

希少な資源をコミットする前に、地図、市場の証拠、競争上の動きを共有方向へまとめ上げます。

## 🧭 **どう育てるか**

- ユーザーニーズ、バリューチェーン、進化段階を結ぶ地図作成サイクルを実践する。
- 前提を定期的に見直し、何が変わったか、その理由を記録する。
- プレモータムやシナリオ思考で戦略的な物語を試す。
