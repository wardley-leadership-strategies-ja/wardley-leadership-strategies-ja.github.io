# ステークホルダー調整と影響力

異なるインセンティブを持つ経営層、チーム、パートナー、規制当局のあいだでコミットメントを確保するスキルです。

## 🎯 **何を可能にするか**

複数の利害にまたがる戦略でも、実行を一貫させられます。

## 🧭 **どう育てるか**

- ステークホルダーの動機を地図化し、抵抗ポイントを予測する。
- 戦略を各ステークホルダーの成功指標へ翻訳する。
- 調整を持続させるフィードバックループをつくる。
