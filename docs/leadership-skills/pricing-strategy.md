# 価格戦略

需要を形づくり、価値を示し、競争ダイナミクスを管理する価格とパッケージを設計する能力です。

## 🎯 **何を可能にするか**

市場での一手、参入障壁、採用加速の中核になります。

## 🧭 **どう育てるか**

- 価格をコストだけでなく、ユーザー価値と進化段階に結びつける。
- 価格変更に対する競争反応をモデル化する。
- 価格実験で弾力性とセグメンテーションを検証する。
