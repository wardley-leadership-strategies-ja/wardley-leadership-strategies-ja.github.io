# システム思考とバリューチェーン思考

より広い状況の中で、コンポーネント、依存関係、インセンティブがどう相互作用するかを見るスキルです。

## 🎯 **何を可能にするか**

バリューチェーンを組み替え、ボトルネックを活用し、エコシステムを調整する場面で不可欠です。

## 🧭 **どう育てるか**

- 依存関係を地図化し、現在どこに支配や摩擦があるかを特定する。
- 重要コンポーネントを変える前に、二次的影響を探る。
- ひとつのノードを動かすことで、パートナー、供給者、ユーザーへどう波及するかを見直す。
