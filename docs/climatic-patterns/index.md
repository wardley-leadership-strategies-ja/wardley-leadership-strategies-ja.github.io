# 状勢パターン

状勢パターンとは、時間をかけて市場を形づくる大きな力学です。個々の組織の行動とは関係なく進行することが多い特徴があります。

こうした傾向を認識することで、リーダーは環境の進化を先読みし、条件が変わる前に戦略を調整できます。
