# 対競合戦略

対競合戦略は、競合の能力、認知、依存関係、内部事情へ直接働きかけるプレイです。市場全体を動かすというより、相手の行動を鈍らせたり、誤らせたり、疲弊させたりして優位を取ります。

前提になるのは、競合のバリューチェーンと慣性をよく知っていることです。相手がどこで無理をしているかを読めなければ、有効な一手にはなりません。

## 🤔 **対競合戦略とは何か**

このカテゴリの手は、競合の意思決定や実行能力そのものへ圧力をかけます。正面衝突より、相手の判断ミス、内部摩擦、依存性の高さを利用する色合いが強いのが特徴です。

## 🎯 **なぜ使うのか**

- 相手の強みをそのまま戦わずに崩せる
- 自社より重い組織や遅い意思決定を逆手に取れる
- 市場全体を壊さずに競争優位を取れる
- 限られた資源でも効果の大きい一手を作りやすい

## ⚠️ **注意点**

誤読すると逆効果です。相手の地図を曖昧に見たまま使うと、こちらの意図が露呈し、報復や規制を招きます。小さな試行で確かめながら圧力を増やすのが基本です。
