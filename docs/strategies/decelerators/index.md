# 減速戦略

減速戦略は、コンポーネントや市場の進化をあえて遅らせるプレイです。収益性の高い旧来領域を守る、適応のための時間を買う、競合の前進を鈍らせる、といった目的で使います。

多くは防御的ですが、競合を足止めする攻撃的な使い方もあります。ただし、使いすぎると自分たち自身の慣性を強めます。

## 🤔 **減速戦略とは何か**

減速戦略は、自然なコモディティ化や普及の流れへ人為的なブレーキをかける手です。複雑さ、費用、制約、法的障壁を増やすことで、変化の速度を落とします。

代表的な型は次のとおりです。

- [制約の創出](/strategies/decelerators/creating-constraints): 新たな制約を作る
- [既存制約の活用](/strategies/decelerators/exploiting-constraint): 既存の制約を増幅する
- [特許と知的財産権](/strategies/decelerators/ipr): 知的財産権で法的な減速をかける

## 🐌 **なぜ使うのか**

- 成熟した収益源を長く守る
- 組織が追いつくための時間を買う
- 競合の速度を下げ、こちらに有利な条件で戦う
- 制御不能な急変がもたらすリスクを抑える

## ⚖️ **加速戦略との違い**

[加速戦略](/strategies/accelerators/)は普及と標準化を早めます。減速戦略はその逆で、進化を遅らせます。実際には、補完財は加速し、自社の利益源を脅かす領域は減速する、といった使い分けがよく起きます。

## ⚠️ **リスク**

- 守りすぎると自社の慣性が強くなる
- 反競争的と見なされ、規制を招く
- パートナーや顧客の信頼を損なう
- 長期的にはより優れた代替手段に迂回される
