# ユーザー認知戦略

ユーザー認知戦略は、価値、リスク、変化、選択肢に対する人々の見え方を動かすプレイです。客観的な性能だけでなく、何が信頼され、何が怖がられ、何が当然だと思われるかが競争結果を左右するという前提に立ちます。

透明な教育から、恐怖や混乱を利用する操作的な手まで含まれるため、効果だけでなく倫理も重要です。

## 🤔 **ユーザー認知戦略とは何か**

このカテゴリのプレイは、認知バイアス、感情、情報格差、社会的証明を使って行動を変えます。製品そのものより「どう見えるか」を変えることで、市場の動きを左右します。

## 💡 **なぜ使うのか**

- 性能差が小さい市場でも優位を作れる
- 新しい行動や採用を早められる
- 競合の勢いを認知面から鈍らせられる
- 制度、評判、信頼を競争要素として扱える

## ⚖️ **倫理面**

教育や透明性は建設的ですが、恐怖・不確実性・疑念（FUD）や意図的な混乱は短期成果の代わりに長期の信頼を失うことがあります。認知を動かす力が強いぶん、どこまでを正当な説得とみなすかを明確にしておく必要があります。
