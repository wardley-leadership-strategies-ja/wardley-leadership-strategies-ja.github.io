# 毒性への対処戦略

毒性への対処戦略は、組織の足を引っ張るレガシー資産、重い依存関係、複雑で扱いにくいバリューチェーンをどう処理するかに関するプレイです。問題は単に古いことではなく、変化コストが高く、進化を妨げていることにあります。

ここで重要なのは、感情ではなく地図で判断することです。何を捨て、何を延命し、何を分解し、何を再構成するかを、ユーザー価値と進化段階から決めます。

## 🤔 **このカテゴリで扱うこと**

毒性は、収益源であり続ける一方で将来の足かせにもなります。このカテゴリの戦略は、切り離す、売る、隠す、再設計するなど、痛みを伴う移行を管理するためのものです。

主な型は次のとおりです。

- [Disposal of Liability](/strategies/dealing-with-toxicity/disposal-of-liability)
- [Pig in a Poke](/strategies/dealing-with-toxicity/pig-in-a-poke)
- [Refactoring](/strategies/dealing-with-toxicity/refactoring)
- [Sweat and Dump](/strategies/dealing-with-toxicity/sweat-and-dump)
- [Value Chain Disaggregation and Re-aggregation](/strategies/dealing-with-toxicity/value-chain-disaggregation-and-re-aggregation)

## 💸 **何もしないコスト**

毒性資産は、会計上の資産であっても、戦略上は将来機会の損失源になります。変えるたびに遅く、高く、政治的になり、結果として新しい賭けへ資源が回らなくなります。

## 🧭 **判断基準**

- ユーザー価値に本当に効いているか
- 右側へ寄りすぎて差別化ではなくなっていないか
- 維持コストより移行コストのほうがまだ低いか
- いま直すべきか、搾り切ってから捨てるべきか
